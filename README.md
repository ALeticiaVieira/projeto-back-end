# Digital Store API

API REST desenvolvida para o projeto Digital Store, utilizando Node.js e Express.

## Tecnologias utilizadas

- Node.js
- Express
- Sequelize
- MySQL
- JWT
- Swagger
- Jest

## Pré-requisitos

- Node.js instalado
- MySQL instalado e configurado

## Instalação

Clone o repositório:

```bash
git clone https://github.com/ALeticiaVieira/projeto-back-end.git
```

Entre na pasta do projeto:

```bash
cd projeto-back-end
```

Instale as dependências:

```bash
npm install
```

## Configuração

Crie um arquivo `.env` na raiz do projeto e configure as variáveis de ambiente necessárias para a conexão com o banco de dados e autenticação JWT.

## Execução

Inicie a API com:

```bash
npm run dev
```

## Documentação da API

A documentação foi desenvolvida com Swagger.

Com o servidor em execução, acesse:

http://localhost:3000/api-docs/#/

## Testes

Execute os testes automatizados com:

```bash
npm test
```
